# Tehdit modeli (STRIDE)

Kapsam: kimlik sunucusu (`src/Selcuk.Identity`), ortak istemci kütüphanesi ve demo uygulamalar, Demo API, Tek Kapı
köprüsünün kimlik sunucusuyla etkileşimi ve ölçüm aracı. Varlıklar: kullanıcı şifresi ve 2FA anahtarı, oturum
çerezleri, yetkilendirme kodu, access/id/refresh token, istemci secret'ları, imzalama anahtarı, denetim kayıtları,
Tek Kapı kasasındaki gerçek sistem şifreleri.

Test adları koddan alındı (`dotnet test --list-tests`, Tek Kapı için `araclar/tek-kapi/test/*.js` kontrol adları).
Durum: **tam** = önlem var ve testle doğrulanıyor; **kısmi** = önlem var ama bilinen bir boşluk kalıyor (sonda
"Açık kalan riskler"); **açık** = önlem yok.

## Açık kalan riskler

| # | Risk | Etki | Olası çözüm |
|---|---|---|---|
| R1 | **Durumsuz JWT access token.** Çıkış veya iptalden sonra access token süresi dolana kadar (en çok **15 dakika**) Demo API'de geçerli kalır; API kimlik sunucusuna sormaz. | Çalınan access token iptalden sonra da kısa süre kullanılabilir. | Token introspection (RFC 7662) veya API'de iptal listesi; daha kısa ömür. Bilinçli olarak yalnızca belgelendi (README > Token yaşam döngüsü). |
